# eShram Data Dictionary

## Source

Dataset: District-wise Demographic Data of Unorganised Workers registered on eShram as on Previous Day

Source: data.gov.in

Data type: Registered eShram worker records

Note: The data is based on self-declaration.

## Dataset Fields

| Field | Description |
|---|---|
| Gender | Gender of the registered worker |
| Age | Age of the registered worker |
| DifferentlyAbledStatus | Disability status of the registered worker |
| EducationQualification | Education qualification of the registered worker |
| CurrentStateCode | Code of the worker's current state |
| CurrentStateName | Name of the worker's current state |
| CurrentDistrictCode | Code of the worker's current district |
| CurrentDistrictName | Name of the worker's current district |
| PermanentStateCode | Code of the worker's permanent state |
| PermanentStateName | Name of the worker's permanent state |
| PrimaryOccupation | Primary occupation of the registered worker |
| DataGovUpdateDate | Date associated with the data record |

## Dataset Size

The portal preview currently shows approximately 343.86 million records.

## Important Limitation

The dataset represents registered eShram workers and is based on self-declared information. It should not be interpreted as a complete census of all unorganised workers in India.
